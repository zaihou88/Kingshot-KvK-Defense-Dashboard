# KvK Defense Board — Player Guide

This is the tool Kingdom 2159 KOR uses to plan Castle Battle defense. If
you're reading this on GitHub, you probably don't need to touch any of the
code below — just open the app link your alliance shared with you and read
on.

## Getting in

You'll be asked for a passcode before you see anything. Your officers will
share this with you — it's the same code for the whole kingdom, not
something personal to you.

## Checking in your stats

Once you're in, you'll land on **Player check-in**. This is where you enter
your numbers so officers can figure out the best defense setup.

- **In-game name** — type it, then click **Load previous entry** if you've
  submitted before. It'll pull up what you entered last time so you only
  need to update what's changed, instead of retyping everything.
- **Alliance** — whichever alliance you're currently in.
- **Power, March size, Troop tier, Castle level** — always asked.
- **Rally size and troop stats** — these only show up once your power
  crosses a certain threshold. If you don't see them, it just means you're
  not there yet — nothing's broken.

If several of you are checking in at once, whoever's entering the data can
use **Bulk entry** instead of doing everyone one at a time. There are two
versions of it: one for regular joiners (just the basics), and one for
anyone who might end up leading a tower (which also asks for troop stats,
since that's what decides who leads). Either one also lets you upload a
CSV or Excel file instead of typing everyone in by hand — download the
template first so your columns line up correctly.

## Reading the Battle Plan

The **Battle plan** tab shows the actual defense setup once officers have
published one — Castle and each turret, with:

- Its target troop mix (e.g. "60% Infantry / 20% Cavalry / 20% Archer")
- Its **Leader** and **Backup Leader**
- Its **Joiners** — everyone else defending there
- Its **Late Joiners** — a backup list in case there's still room

If it says nothing's been published yet, check back closer to the actual
battle — officers are still finalizing things.

This is a snapshot, not a live view — if officers are still adjusting
things behind the scenes, you won't see those changes here until they
publish again. So if something looks off, it might just be outdated;
worth asking in Discord before assuming it's wrong.

## Questions

If something's confusing or looks broken, ask in the alliance Discord
rather than trying to fix it yourself — officers can see and adjust
everything from their side.
